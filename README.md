# claudeos-site

The homepage and privacy policy for ClaudeOS, the private assistant system of Arenas Molina
Group Ltd. Google requires both pages before an External OAuth app can be published to
production. Served by GitHub Pages at https://claudeos.arenasmolinagroup.com.

Plain HTML and one stylesheet. No build step, scripts, cookies, analytics or external requests.

| File | Served at |
| --- | --- |
| `index.html` | `/` |
| `privacy.html` | `/privacy` |
| `CNAME` | Custom domain for GitHub Pages |

When Arenas Molina Group's own website goes live with its privacy notice, point the Google
OAuth branding at that instead, and keep or retire this site.
